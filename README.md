# ARCOSUY — Landing Tableros de Basket

Landing standalone para preview de la sección de Tableros de basket.

## Contenido

- `index.html` — página completa (HTML + CSS + JS inline)
- `img/` — hero, fotos de tableros, logo
- `favicon.png`

## Deploy

Conectado a **Cloudflare Pages** vía GitHub — cada push a `main` publica automáticamente.

URL preview: https://arcosuy-tableros-de-basket.pages.dev

## Preview local

Abrir `index.html` directo en el navegador, o servir con cualquier server estático (http-server, Live Server, etc.).
